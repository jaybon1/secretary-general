# 우리가 겪은 사례

새 사례는 여기에 바로 쓰지 않는다. 일하는 폴더의 `notes/pending/`(없으면 보고서 끝)에 "사이트, 막힘, 뚫은 방법, 날짜"로 남기고, 사용자가 검토해서 옮긴다.

| 사이트 | 막힘 | 뚫은 방법 | 날짜·근거 |
|---|---|---|---|
| 쿠팡 검색 결과 | Ego Lite로 검색 결과 주소에 바로 가면 '사용권한 없음' | 홈 → 검색창에 입력 → Enter로 통과 | 2026-10-23, 1회 시도(재현 횟수 적음) |
| 네이버 지도 목록 | 전체 snapshot에서 목록이 안 읽힘(iframe) | `iframe` 줄 ref로 `snapshot({ scope: "subtree", root })` | 날짜 확인 안 됨 |
| 네이버 쇼핑 | 캡차 | 사용자가 한 번 풀면 홈·검색 주소 모두 한동안 통과. 지속 시간은 확인 안 됨 | 날짜 확인 안 됨 |
| 네이버 계열 전반(Claude in Chrome) | 확장이 열지 않음 | 사이트 차단이 아니라 확장 자체 제한. Ego Lite나 m. 주소로 | 날짜 확인 안 됨 |
| 알림 권한 창이 뜨는 사이트 | 권한 창 때문에 진행 멈춤 | 조사 순서 맨 뒤로. 멈추면 WebFetch로 대신 읽고 보고서에 "원문 미저장" 표시 | 날짜 확인 안 됨 |
| 네이버 블로그(데스크톱) | 200인데 본문 없음(2,852B, iframe 1개) | `m.blog.naver.com` 25,719B. RSS `rss.blog.naver.com/<id>.xml`도 됨 | 2026-11-02, `run.ps1 fetch --variants` |
| Reddit 서브레딧 페이지 | 지문 없는 요청 403 "Blocked" | `.rss` 피드(크롬 지문으로 200) | 2026-11-02, `run.ps1 fetch` |
| Pexels 검색·항목 페이지 | 브라우저 없이(curl_cffi chrome) 받으면 403 CHALLENGE(Cloudflare) | Ego Lite로 검색 주소 직행 18회 + 항목 페이지 21개, 막힘 없음 | 2026-11-15, 한 Space에서 연달아 1회 |
| e뮤지엄(emuseum.go.kr)·공유마당(gongu.copyright.or.kr) 검색 | 검색 결과 주소로 바로 가면 오류 페이지·"콘텐츠 준비중" | 홈 → 검색창 입력 → Enter | 2026-11-15, 1회 |

## 제안 양식

```
사이트: <호스트와 페이지 종류>
막힘: <어느 단계(WebFetch/스크립트/Ego Lite)에서, 무엇이 보였나(판정 이름·문구)>
뚫은 방법: <한 일. 못 뚫었으면 "못 뚫음"과 멈춘 지점>
날짜: <YYYY-MM-DD> / 시도 횟수: <n>
```
