# 로컬 미리보기·시안 페이지

## 페이지 만들기

- 시안이 여럿이면 HTML 한 장에 시안마다 이름을 붙여 나란히 둔다. 움직이는 것은 반복 재생과 정지 화면을 함께 준다.
  이유: 사용자는 원격(폰, 다른 PC)에서도 경로 하나로 한눈에 비교해 고른다.
- 주소에는 쿼리스트링(`?still`, `?only=` 등)을 붙이지 않는다. 정지 화면, 시안 고르기, 자막·효과음 켜고 끄기 같은 옵션은 페이지 안 버튼으로 바꾸게 만든다.
  이유: 로컬 파일 경로에 쿼리가 붙으면(`file:///…/a.html?still`, `X:\…\a.html?still`) 크롬이 `?`를 `%3F`로 바꿔 파일을 찾지 못한다. 사람이 고를 것은 버튼으로 두어야 원격에서도 누를 수 있다.
- 외부 링크(https)의 쿼리스트링은 그대로 둔다(이 규칙은 로컬 파일 주소에만 해당한다).
- 페이지가 쓰는 파일(영상, 그림, 글꼴)은 페이지 옆 상대 경로로 둔다.
  이유: 다른 PC가 같은 폴더를 다른 드라이브 이름으로 열어도 그대로 열린다.

## 주소를 보고에 적기

- 파일로 열리는 미리보기는 이 PC의 전체 경로를 적는다. 다른 PC·폰에서 여는 경로와 링크는 비서가 붙여 전한다.
  이유: 다른 PC에서 이 PC 폴더를 보는 경로(공유 드라이브 이름 등)는 PC마다 달라 비서 설정에만 있다. 업무 세션이 짐작해 적으면 틀린 경로가 사용자에게 간다.
- 서버가 필요한 미리보기(로컬 개발 서버 등)는 띄운 포트와 함께 `http://localhost:<포트>/`를 적고, 다른 기기에서 여는 주소도 적는다. 다른 기기용 주소의 호스트는 `node <bin>\dashboard.mjs urls`(`common-secretary-programs` 스킬)가 내는 주소 가운데 `127.0.0.1`이 아닌 것의 호스트를 쓰고 포트만 미리보기 포트로 바꾼다. 그 명령이 없거나 `127.0.0.1`만 내면 localhost 주소만 적고 "다른 기기 주소 확인 안 됨"으로 적는다.
  이유: 이 PC의 사설망 주소는 PC마다 달라 스킬·규칙에 숫자로 적지 않는다.
- 서버로 띄운 미리보기는 다음 미리보기를 만들 때까지 띄워 두고, 다음 미리보기를 띄우기 바로 전에 앞의 것을 끈다. 마지막 미리보기는 최종 승인(렌더·배포 승인)을 받으면 끈다. [질문]에는 띄워 둔 주소와 끌 명령을 적는다.
  이유: 사용자는 [질문]을 받은 뒤 원격에서 미리보기를 열어 보고 고칠 점을 말한다. 고친 판이 나오기 전까지 앞 판을 다시 볼 수 있어야 하고, 판마다 서버가 쌓이면 포트와 메모리를 잡는다.
