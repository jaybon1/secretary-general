# 맡긴 업무를 묻거나 결과물을 보여 달라고 할 때 (순서 5·6단계)

5. "그 업무 어떻게 됐어?"에는 `list_tasks` / `get_task`로 답한다. "업무 브리핑"처럼 전체를 물으면 돌고 있거나 기다리는 업무(`status` running·asking·ready)만 보고, 끝난 업무는 그 업무를 물을 때만 꺼낸다.
6. **결과물을 아티팩트로 보여 달라고 하면** (사용자가 요청할 때만): Artifact 도구는 이 비서 설정(`.claude/settings.json`의 `deny`)에서 꺼 두었다(컨텍스트를 줄이려고 정한 설정). 그래서 아티팩트로 올리지 않고 결과물의 경로와 폰에서 여는 링크로 보여 준다. 비서는 결과 파일을 직접 읽지 않는다(비서 대화에 파일 내용이 쌓이지 않게).
   - `get_task`로 그 업무의 결과 폴더와 결과물 파일(보고서에 적힌 결과물 경로)을 확인한다.
   - AGENTS.md "경로" 절대로 보여 준다: 경로 하나마다 코드 블록 하나, 결과물 상위 폴더 안이면 이 PC 경로 블록 아래 다른 PC 경로 블록과 그 아래 폰에서 누르면 열리는 주소 링크 한 줄(세션 시작 때 `<secretary-paths>`가 알려 준 값). HTML 결과물은 그 링크로 폰에서 바로 열린다.
   - HTML이 아닌 결과물(마크다운, 표 등)을 폰에서 보기 좋게 보고 싶다고 하면, 업무 세션에 send-worker(`background-session.md` 2번)로 "결과 폴더의 <파일>을 보기 좋은 HTML 페이지로 같은 폴더에 만들고 그 경로만 한 줄로 답하라"를 보내고, 받은 경로를 위처럼 보여 준다. 업무 세션이 없으면(종료·보관) 파일이 생기는 일이라 새 업무로 맡긴다.
   - 사용자가 꼭 아티팩트로 보고 싶다고 하면 Artifact 도구가 꺼져 있어 못 한다고 알리고, 다시 켤지 묻는다(AGENTS.md "개발 메모"의 꺼 둔 도구 규칙).
