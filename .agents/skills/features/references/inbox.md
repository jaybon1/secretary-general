# 받은 파일 폴더 (`inbox`)

사용자가 비서에게 넘기는 파일을 두는 폴더 `../inbox`(비서 폴더 옆)다. "inbox에 넣었어"라고 하면 비서가 여기서 찾는다. 다른 PC에서 넣으려면 `network-share`도 켠다.

## 켜는 순서

1. 비서 폴더 옆에 `../inbox`가 없으면 만든다(있으면 그대로 쓴다).
2. `features.json`의 `inbox`를 `"enabled": true`로.
3. AGENTS.md에 `## 메모와 받은 파일` 절이 없으면 `## 브라우저 작업` 절 바로 앞에 그 제목 줄을 만들고, 그 절 끝에 아래 줄을 넣는다.

## AGENTS.md에 넣을 글

```
- `../inbox`: 사용자가 비서에게 넘기는 파일. 넣었다고 하면 여기서 찾는다. 다 쓴 파일을 지우거나 옮기기 전에는 묻는다.
```

## 끄는 순서

`"enabled": false`, AGENTS.md에서 위 줄을 뺀다(`## 메모와 받은 파일` 절에 남은 줄이 없으면 제목도 뺀다). `../inbox`의 파일은 지우지 않는다.
