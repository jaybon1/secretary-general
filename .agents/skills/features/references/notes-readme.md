# 정리 규칙

이 볼트는 사용자가 비서에게 말한 내용을 비서가 정리해 쌓는 곳이다. 사용자는 읽고, 비서가 쓴다.
비서가 알아야 할 짧은 사실·결정은 비서 기억에 두고, 여기에는 사용자가 읽을 정리 문서를 둔다.

## 폴더 (PARA)

| 폴더 | 무엇을 | 예 |
|---|---|---|
| `0_Inbox` | 어디 둘지 애매한 것. 잠깐 두고 나중에 옮긴다 | 떠오른 생각 한 줄 |
| `1_Projects` | 끝이 있는 일 | 이사 준비, 블로그 시작 |
| `2_Areas` | 끝없이 관리하는 영역 | 건강, 집안일, 일 |
| `3_Resources` | 관심 주제와 참고 자료 | AI 도구, 요리법 |
| `4_Archives` | 끝났거나 접은 것 | 끝난 프로젝트 |
| `templates` | 노트 틀 | |

- 프로젝트가 끝나면 노트를 `4_Archives`로 옮긴다(지우지 않는다).
- 한 폴더에 노트가 많아지면 하위 폴더를 만든다(예: `1_Projects/이사 준비/`).

## 노트

- 글 종류와 '컴퓨터 없이 볼 것' 여부는 폴더가 아니라 앞머리 정보(`type`, `offline`)로 나눈다.
- 한 주제 = 한 노트. 이미 있는 노트는 사용자가 고치라고 할 때만 고친다(같은 주제 노트가 있으면 알리고 묻는다). 고치면 맨 아래 `변경 기록`에 날짜와 무엇을 바꿨는지 한 줄 남긴다.
- 노트 이름은 주제를 그대로 한국어로 쓴다(날짜를 붙이지 않는다).
- 관련 노트는 `[[노트 이름]]`으로 잇는다.
- 새 노트는 `templates/노트.md` 틀로 만든다.

## 앞머리 정보

```yaml
type: 기술문서 | 아이디어 | 정리 | 프로젝트 | 참고
created: 2026-01-01
updated: 2026-01-01
tags: []
offline: false      # 컴퓨터 없이 볼 내용이면 true
status: 초안 | 진행 | 완료 | 보류
related: []
source: 어디서 옮겼는지   # 출처(주소나 어디서 옮겼는지), 없으면 뺀다
```

## 비서가 지키는 것

- 먼저 묻지 않는다. "정리해줘", "메모해줘"라고 할 때만 대화 기록과 기억을 찾아 쓴다.
- 노트를 만들거나 고치면 `index.md`에 목록을 맞추고 `log.md`에 한 줄 남긴다.
- 확인하지 않은 내용은 "(짐작)" 또는 "확인 안 됨"을 붙인다.
- 노트를 만들거나 고치면 그 노트와 이어진 노트, `index.md`만 점검한다(어긋난 내용, 끊긴 링크). 볼트 전체 점검은 사용자가 요청할 때만 한다.
