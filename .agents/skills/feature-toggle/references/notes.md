# 메모 볼트 (`notes`)

사용자가 말한 내용을 비서가 마크다운 노트로 정리해 쌓는 폴더 `../notes`(비서 폴더 옆)다. 옵시디언(Obsidian)으로 열면 노트끼리 링크로 이어 볼 수 있다(옵시디언은 없어도 된다). 비서는 "정리해줘/메모해줘"라고 할 때만 쓴다. 비서용 짧은 사실·결정은 여기 말고 기억에 둔다.

## 켜는 순서

1. 비서 폴더 옆에 `../notes`가 이미 있으면 그 안을 보여 주고 그대로 쓸지 묻는다(남의 파일을 덮지 않는다). 없으면 만든다.
2. 볼트 뼈대를 만든다(이미 있는 파일은 건드리지 않는다):
   - 폴더 `0_Inbox`, `1_Projects`, `2_Areas`, `3_Resources`, `4_Archives`, `templates`
   - `README.md` ← 이 폴더의 `notes-readme.md`를 그대로 복사
   - `templates/노트.md` ← 이 폴더의 `notes-template.md`를 그대로 복사
   - `index.md`: `# 목차`, 빈 줄, `정리 규칙은 [[README]]. 노트를 만들거나 옮기면 비서가 이 목록을 맞춘다.`, 그리고 `## 1_Projects`부터 `## 4_Archives`까지 제목만
   - `log.md`: `# 정리 기록`, 빈 줄, ``최신이 위. 형식: `- 날짜 시각 | 만듦/고침/옮김/점검 | [[노트]] | 무엇을` ``
3. `features.json`의 `notes`를 `"enabled": true`로.
4. AGENTS.md에 `## 메모와 받은 파일` 절이 없으면 `## 브라우저 작업` 절 바로 앞에 그 제목 줄을 만들고, 그 절 끝에 아래 "목록 줄"을 넣는다. 그리고 `## 정리` 절의 첫 항목 바로 아래에 아래 "정리 줄"을 넣는다.

## AGENTS.md에 넣을 글

목록 줄(`## 메모와 받은 파일` 절):

```
- `../notes`: 사용자가 말한 내용을 비서가 정리해 쌓는 옵시디언 볼트(PARA 구조, 규칙은 `../notes/README.md`). 비서가 마크다운으로 직접 쓴다. 사용자가 "정리해줘/메모해줘"라고 할 때만 대화 기록과 기억을 찾아 쓴다. 이미 있는 노트도 사용자가 고치라고 할 때만 고친다(같은 주제 노트가 있으면 알리고 묻는다). 비서용 사실·결정은 기억에 둔다.
```

정리 줄(`## 정리` 절 첫 항목 바로 아래):

```
- 노트를 만들거나 고치면 그 노트와 이어진 노트, `index.md`만 비서가 직접 점검한다(어긋난 내용, 끊긴 링크). `../notes` 전체 점검은 사용자가 요청할 때만 run-job(Sonnet)으로 돌리고, 고칠 것은 번호 붙여 제안한다.
```

## 끄는 순서

`"enabled": false`, AGENTS.md에서 위 두 글을 뺀다(`## 메모와 받은 파일` 절에 남은 줄이 없으면 제목도 뺀다). `../notes`의 노트는 지우지 않는다.
