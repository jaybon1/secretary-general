# 기능 켜고 끄기

기능 목록은 비서 폴더 맨 위 `features.json`이다. `core`인 기능은 언제나 켜져 있고, 선택 기능은 `"enabled"`로 켜고 끈다. 꺼진 기능은 파일은 그대로 있지만 설치 상태 점검·질문마다 붙는 알림·예약 작업 등록을 건너뛰고, 규칙(AGENTS.md의 글)도 넣어 두지 않아 비서가 쓰지 않는다. 켜고 끄기는 비서 자신에 관한 일이라 비서가 직접 한다. 단계가 끝날 때마다 한 줄로 진행을 남긴다.

기능마다 할 일은 `references/<기능 id>.md`에 있다. 켤 때·끌 때 그 파일만 읽는다.

| id | 기능 | 처음 |
|---|---|---|
| `usage-poll` | 사용량 뒤에서 조회(고른 공급자를 5분마다, 토큰 0) | 켜짐 |
| `idle-jobs` | 쉬는 시간 작업(상황판 미리 갱신, 기억 자동 정리) | 켜짐 |
| `browser` | 브라우저 작업(Ego Lite, Claude in Chrome) | 켜짐 |
| `calendar` | 일정을 Google Calendar에 바로 기록 | 꺼짐 |
| `notes` | 메모 볼트(`../notes`, 옵시디언) | 꺼짐 |
| `inbox` | 받은 파일 폴더(`../inbox`) | 꺼짐 |
| `network-share` | 다른 PC에서 비서 상위 폴더 보기(네트워크 공유) | 꺼짐 |
| `multi-subscription` | 다중 구독: 구독이 둘 이상일 때 가장 여유 있는 다른 계정(b, c…)으로 일 넘기기 | 꺼짐 |
| `external-providers` | 구독 밖 공급자(API 키, Bedrock, 게이트웨이, 다른 회사 CLI) | 꺼짐 |
| `dashboard` | 대시보드: 상태 화면과 결과물 폴더를 폰 브라우저로 읽기 전용으로 보기 | 꺼짐 |
| `phone-push` | 끝 알림: 답이 끝날 때마다 첫 줄을 이 PC의 ntfy 서버로 보내 폰 앱에 띄우기 | 꺼짐 |
| `mistake-guards` | 실수 막기 장치: 답변 검사(영어 답, 경로 표기), 폴더 위치 막기, 질문 알파벳 알림, 위임 앞뒤 대조, 실수 기록 | 켜짐 |

## 보여 주기

`features.json`을 읽어 선택 기능마다 한 줄(이름, 무엇을 하는지, 지금 켜짐/꺼짐)로 보여 준다. 묻지 않은 기능을 켜자고 권하지 않는다.

## 켜기

1. `references/<id>.md`를 읽고, 켜면 무엇이 생기는지(폴더, 예약 작업, 설정, 바깥 서비스, 비용)와 사용자가 직접 할 일(키 넣기, 커넥터 연결, 관리자 PowerShell 실행)을 먼저 말하고 승인받는다. 짧은 승인을 설치 승인으로 넓혀 읽지 않는다(AGENTS.md).
2. 승인받으면 참고 파일의 "켜는 순서"대로 한다. 늘 하는 것:
   - `features.json`에서 그 기능의 `"enabled"`를 `true`로.
   - 참고 파일의 "AGENTS.md에 넣을 글"을 적힌 자리에 글자 그대로 넣는다(앞뒤 빈 줄 하나). 이미 있으면 다시 넣지 않는다.
   - 그 기능에 스킬이 있으면(`features.json`의 그 기능 `files`에 `.agents/skills/<이름>/`) `node src/cli.ts skill-links`로 `.agents/skills-off/<이름>/`에 있던 스킬 폴더를 `.agents/skills/<이름>/`으로 옮긴다. 끌 때는 같은 명령이 다시 `.agents/skills-off/`로 옮긴다(꺼진 기능의 스킬은 어느 CLI도 읽지 않는 그 자리에 두어 비서가 스스로 부르지 않게 한다. 사용자가 고친 내용은 폴더째 함께 간다).
   - AGENTS.md에서 그 기능을 "꺼 둔 기능"으로 적은 문장(`## 처음 쓸 때`의 꺼 둔 기능 목록, 다중 구독·구독 밖 공급자면 `### 공급자` 첫 문단의 "꺼진 기능이고")에서 그 기능을 뺀다. 끌 때는 다시 넣는다.
3. 마치면 `node src/cli.ts setup-check`로 빠진 것이 없는지 보고, 출력의 해당 항목을 전한다.
4. 규칙이 바뀌었으니 새 세션(`/clear`)부터 그 기능이 쓰인다고 알린다.

## 끄기

1. 끄면 무엇이 멈추는지 말하고 승인받는다.
2. `"enabled"`를 `false`로, AGENTS.md에서 그 기능의 글을 빼고, 참고 파일의 "끄는 순서"를 한다(예약 작업 해제 등).
3. 켤 때 만든 폴더·노트·받은 파일·키 파일은 지우지 않는다. 지우려면 따로 묻는다.

## 지킬 것

- 키 값·비밀번호는 대화로 받지 않는다. 사용자가 키 폴더의 파일에 직접 넣게 한다(AGENTS.md "공급자").
- PC 설정을 바꾸는 단계(예약 작업, 네트워크 공유, 방화벽, 계정 만들기)는 실행할 명령을 먼저 보여 주고, 관리자 권한이 필요한 것은 사용자에게 실행을 부탁한다.
- 켜고 끈 것(`features.json`, AGENTS.md)은 사용자 수정으로 남는다. 나중에 업데이트하면 `secretary-update` 스킬이 지키고 묻는다.
- 꺼진 기능이 core 기능의 규칙과 부딪히면(예: 다중 구독을 켜면 일을 넘기는 기준이 바뀜) 참고 파일에 적힌 대로만 고친다. 적혀 있지 않은 곳을 고쳐야 할 것 같으면 묻는다.
