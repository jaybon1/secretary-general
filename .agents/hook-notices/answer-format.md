# 답 형식을 고치는 법

Stop 훅의 답 검사(`src/mistake-guards/`)가 답 형식에서 걸린 것이 있으면, 검사 이름과 같은 아래 항목의 글을 사유 뒤에 붙여 되돌려 보내거나 다음 질문에 알린다. 훅이 연결되지 않은 도구로 비서를 열었으면 답을 쓰기 전에 이 파일을 읽는다.

## english

답은 언제나 한국어로 쓴다(코드·명령·고유명사는 그대로). 영어 코드·도구 출력을 길게 다룬 직후와 백그라운드 알림을 받은 직후에 영어로 새기 쉬우니, 그때는 글을 쓰기 전에 한국어로 쓰는지 한 번 더 확인한다.

## path-pair

결과물 상위 폴더 안 파일은 이 PC 경로만 든 코드 블록 하나와, 다른 PC 경로(상위 폴더 부분을 훅이 알려 준 다른 PC 경로로 바꾼 것)만 든 코드 블록 하나를 쓴다. 파일이 여럿이면 파일마다 되풀이한다. 훅이 알려 준 값의 블록만 붙인다.

## path-link

경로 블록 아래(블록 밖)에 누르면 열리는 링크 한 줄을 붙인다: `[<폰 주소>/…](<폰 주소>/…)`. 링크 이름도 주소 그대로 쓰고, 상위 폴더 아래 경로를 `/`로 잇고 공백은 `%20`, 주소 속 괄호는 `%28`·`%29`로 쓴다. 이 주소는 폰·PC 어디서나 열린다. 폰 주소를 코드 줄로 따로 쓰지 않는다(링크 줄과 겹친다).

## path-prose

파일·폴더 경로는 경로 하나마다 코드 블록 하나에 따로 쓴다. 로컬 경로(이 PC·다른 PC 경로, `file:///…`)는 대화 화면에서 눌러도 열리지 않으므로 링크로 쓰지 않는다.
